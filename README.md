# Alameda 3D

Mapa 3D interactivo de la Galería Alameda en Cali con MapLibre GL JS, deck.gl y contexto demográfico del CNPV 2018 del DANE.

## Publicación rápida

1. Sube `index.html`, `styles.css` y `app.js` al repositorio.
2. Activa GitHub Pages desde la rama `main` y carpeta `/root`.
3. Abre la URL publicada.

## Tecnologías

- MapLibre GL JS
- deck.gl
- DANE ArcGIS REST Service
